# 시장 분석 기사 읽기 도우미 (크롬 확장 프로그램)

서버가 자동으로 읽지 못한 해외 기사(봇 차단, 스크립트로 그리는 본문 등)를 **사용자 크롬**으로 열어 본문을 서버에 넘깁니다.
서버는 받은 페이지를 평소와 같은 방식(AI 요약·번역, 본문 기준 호재/악재 판정)으로 처리합니다.

## 설치

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 `browser_extension` 폴더 선택
4. 열려 있던 `http://127.0.0.1:9000/market-trend` 탭을 새로고침

코드를 고친 뒤에는 `chrome://extensions`에서 이 확장 프로그램의 새로고침 버튼을 누릅니다.

## 사용

- **막힌 기사 브라우저로 요약**: 기사 목록 필터 줄 끝의 버튼. 화면에 보이는 위쪽 20건 중 서버가 읽지 못한 기사만
  백그라운드 탭으로 하나씩 열어 읽고 탭을 닫습니다. 매체에 부담을 주지 않도록 한 건씩, 2.5초 간격으로 처리합니다.
- **기사를 직접 열 때**: 요약되지 않은 기사의 제목을 눌러 원문을 열면, 페이지가 다 열린 뒤 자동으로 본문을 읽어 보냅니다.
  탭은 닫지 않습니다. 사람 확인 화면이 뜨면 통과한 뒤 다시 읽습니다.

## 동작 범위와 한계

- 사람 확인(Cloudflare 등) 화면이나 빈 페이지는 서버로 보내지 않고 "직접 열어 주세요"라고 표시합니다.
- 유료 기사는 구독·로그인한 상태여야 본문이 보입니다. 미리보기만 보이면 그만큼만 요약됩니다.
- 확장 프로그램은 `127.0.0.1:9000`/`localhost:9000` 화면에서 온 요청만 처리하고, 서버는 `X-Toss-Extension` 헤더가 있는
  요청만 받습니다. 다른 웹사이트가 이 서버로 기사 요약을 요청할 수 없습니다.
- 브라우저로 읽은 유료 기사 요약은 개인 용도로만 쓰세요. 서비스를 공개하면 다른 사용자에게 보이지 않게 해야 합니다.
